# Publication checklist

- [x] Public source is isolated from the operational workspace.
- [x] Generated caches and bytecode are excluded.
- [x] Local models, raw evidence, sandboxes, nested Git histories, and project support files are excluded.
- [x] Public tree contains no detected API keys, private keys, or hardcoded lab credentials.
- [x] Unit and adversarial tests pass.
- [x] Package inventory and hashes verify.
- [x] Select and add an open-source license approved by the repository owner: Apache 2.0.
- [ ] Configure GitHub private vulnerability reporting after repository creation.
- [ ] Enable branch protection and require the test workflow before merge.
- [ ] Upload `docs/assets/social-preview.png` as the GitHub repository social preview.

Do not publish this repository until the license item is complete.
